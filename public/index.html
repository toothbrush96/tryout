Trainings-Cockpit einrichten

Dein Garmin Personal API-Schlüssel wird mit deinem Passwort verschlüsselt auf dem Server gespeichert. Er erscheint nie im Browser, in URLs oder in Logs.

Schlüssel erstellen: Garmin Connect → Einstellungen → Personal API Token. Der Schlüssel wird vor dem Speichern bei Garmin geprüft.
